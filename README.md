# Grand Multiplayer Adventure

A mod for **Grand Mountain Adventure: Wonderlands** (Steam) that puts everyone on the same mountain and shows every other player skiing in real time. 

## Usage

Every player needs the mod. Download `GMA-Multiplayer-Setup.exe` from the latest build (the GitHub Actions artifact, or a Release), close the game and run it.

**Host:** on your router, forward **UDP 47800** to your PC, then give your friends your public IP. 

 **Settings > Multiplayer**, click **Host address**, type the host's IP and press Enter, then set **Mode** to **Join**.
